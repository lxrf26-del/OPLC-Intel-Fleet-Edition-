# OpenCore Legacy Patcher: Intel Fleet Edition (OCLP-Intel)

Welcome to the **Intel Fleet Edition** of OpenCore Legacy Patcher. This project is a dedicated fork of Dortania's OpenCore Legacy Patcher, purposefully maintained and optimized to breathe modern life into the complete 2007–2019 Intel Mac fleet.

As Apple shifts its focus entirely to Apple Silicon, this fork focuses strictly on stabilizing, refining, and extending modern macOS support for the machines that defined an era—from early silver-tower Mac Pros and classic unibody MacBooks to the final high-end Intel iMacs and 16-inch MacBook Pros.

## 🚀 Key Features of this Fork
* **Broad Fleet Support:** Tailored optimizations spanning hardware from **2007 to 2019**.
* **Streamlined Codebase:** Focused strictly on Intel architecture requirements to keep builds efficient.
* **Targeted Patches:** Integrated stability improvements for graphics kexts, legacy Wi-Fi/Bluetooth, and modern audio frameworks under newer macOS versions.

## 💻 Supported Generations
This fork is designed to cover the absolute lifecycle of classic Apple-Intel hardware:
* **Vintage Fleet (2007–2011):** Non-Metal GPU machines, early unibody designs, and classic silver Mac Pros.
* **Retina & Metal Fleet (2012–2015):** The legendary mid-2012 unibodies, early Retina displays, and trashcan Mac Pros.
* **Late-Stage Intel Fleet (2016–2019):** Touch-bar MacBook Pros, 5K iMacs, and the final high-end Intel powerhouses dropping official Apple support.

## 🏗️ Getting Started

### Prerequisites
* A Mac from the 2007–2019 timeline.
* Xcode Command Line Tools installed (`xcode-select --install`).
* Python 3.10 or newer.

### Building from Source
1. Clone this repository:
   ```bash
   git clone https://github.com
   cd OCLP-Intel-Fleet-Edition
   ```
2. Install the necessary Python requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run or compile the patcher using the built-in build scripts.
